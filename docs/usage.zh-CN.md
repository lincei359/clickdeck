# 点点快捷

通过鼠标点击执行快捷键的 Windows 桌面悬浮工具栏。可只显示一个复制按钮，也可显示全部按钮；支持自定义快捷键和常用文字。

## 开始使用

1. 双击 `ClickDeck.exe`。无需安装，适用于带有 .NET Framework 4.8 或更高版本的 Windows 10 / 11。
2. 先在需要操作的软件中点击输入位置或选中文字，再点击悬浮栏按钮。
3. 点击工具栏不会抢走原窗口的输入焦点。复制、粘贴、全选等操作会发送到原窗口。
4. 按住工具栏顶部空白区域，可拖动到屏幕上的其他位置。

## 选择和编辑按钮

点击悬浮栏右上角的 `···`，打开编辑窗口。

- **只显示复制**：选中左侧的“复制”，点击“只留选中”，再点击“保存并应用”。
- **显示全部**：点击“全选”，再保存。
- **自由选择**：勾选要显示的按钮，取消勾选不需要的按钮。
- **调整顺序**：选中一项，点击 `↑` 或 `↓`。
- **添加快捷键**：点击“＋ 添加”，填写名称和组合键，例如 `Ctrl+Shift+S`。也可用“录制按键”；Win 组合键直接填写。
- **添加常用文字**：添加按钮，将操作类型改为“输入文字”，填写文字后保存。支持中文、表情、Tab 和多行文字，每个按钮最多 4,000 个字符。
- **删除按钮**：选中一项后点击“删除”，保存后生效。
- **布局和外观**：每行可显示 1–6 个按钮，可启用紧凑尺寸、隐藏快捷键提示、调整透明度。
- **取消编辑**：点击“取消”或关闭编辑窗口，丢弃本次尚未应用的修改。

最多保存 80 个按钮。按钮超过屏幕高度时，悬浮栏可滚动。全部取消勾选后仍能通过 `···` 重新添加按钮。

## 默认操作

| 按钮 | 快捷键 | 首次运行显示 |
| --- | --- | --- |
| 复制 | Ctrl+C | 是 |
| 粘贴 | Ctrl+V | 是 |
| 全选 | Ctrl+A | 是 |
| 剪切 | Ctrl+X | 否 |
| 撤销 | Ctrl+Z | 是 |
| 重做 | Ctrl+Y | 否 |
| 回车 | Enter | 是 |
| 换行 | Shift+Enter | 是 |
| 退格 | Backspace | 否 |
| 删除 | Delete | 否 |
| 保存 | Ctrl+S | 否 |
| Tab | Tab | 否 |
| 取消 | Esc | 否 |

按键的具体效果由目标软件决定。例如，Enter 在部分聊天软件中会发送消息，而 Shift+Enter 会换行。重做也可按目标软件的需要修改为 Ctrl+Shift+Z。

## 隐藏、恢复和退出

- 点击悬浮栏右上角的 `−` 隐藏。
- 双击右下角系统托盘中的绿色图标，恢复悬浮栏；右键图标也可显示、隐藏、编辑或退出。
- 再次双击 `ClickDeck.exe` 会恢复已有悬浮栏，不会启动第二份软件。
- `Ctrl+Alt+Space` 可切换显示和隐藏。如被其他程序占用，编辑窗口会显示托盘操作提示。
- 退出软件：右键系统托盘图标，选择“退出点点快捷”。

## 设置与文件

按钮、布局、透明度和位置自动保存在：

`%LOCALAPPDATA%\ClickDeck\settings.json`

软件只在点击按钮时发送按键，不联网、不收集操作记录，不修改开机启动项。将软件文件夹删除即可移除程序；需要一并重置设置时，在退出软件后删除上述配置文件。

程序文件：`ClickDeck.exe`；托盘图标：`ClickDeck.ico`。建议将整个文件夹保留在一起。源码仓库中的 `source` 是完整源码和构建、验证脚本；`docs/preview.png` 是界面示例。

## 无反应时

先点击目标软件的输入位置，再点击悬浮按钮，并松开键盘上的 Ctrl、Shift、Alt、Win。检查是否仍开着点点快捷的编辑窗口；关闭编辑窗口后再操作。

Windows 会限制普通权限程序向管理员权限窗口发送按键。如果目标程序以管理员身份运行，点点快捷也需要以管理员身份运行。此限制来自 [Microsoft SendInput 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)。部分游戏、受保护窗口或自定义输入控件也可能不接受模拟按键。

## 修改源码

在 `source` 文件夹中运行 `build.ps1`，会重新生成 `ClickDeck.exe`。使用 Windows 自带的 .NET Framework C# 编译器，无需下载第三方包。

`source/tests/run-tests.ps1` 使用独立测试编辑器检查实际鼠标点击、快捷键发送、焦点保持、配置读写和按钮编辑。测试期间会暂时占用鼠标、焦点和剪贴板，结束后恢复；请在无需操作电脑时运行。

本机验证：73 项检查通过，包括 Ctrl+C / V / A / Z、Enter、Shift+Enter、自定义 Ctrl+Shift+S、中文和表情输入、只显示一个按钮、显示全部按钮、录制快捷键和取消编辑。不同第三方软件中的效果仍取决于该软件对快捷键的处理。
